# Student Grade Tracker

## Project Overview
The Student Grade Tracker is a Java-based application developed as part of the CodeAlpha Java Programming Internship. It helps users manage student marks and generate a summary report.

## Features
- Input student names and marks.
- Store student data using arrays.
- Calculate average marks.
- Identify the highest and lowest marks.
- Display a complete student grade report.
- Validate student marks between 0 and 100.

## Technologies Used
- Java
- Scanner class
- Arrays
- Eclipse IDE

## How to Run
1. Download `StudentGradeTracker.java`.
2. Open Eclipse IDE.
3. Create a Java project named `StudentGradeTracker`.
4. Add the Java file to the `src` folder.
5. Run the program as a Java Application.
6. Enter the number of students, their names, and marks.

## Output
The program displays each student's marks, average marks, highest marks, and lowest marks.
