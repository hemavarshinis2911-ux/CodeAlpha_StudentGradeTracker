# CodeAlpha Java Programming Internship Projects

This repository contains my Java programming projects completed as part of the CodeAlpha Java Programming Internship.

## Task 1: Student Grade Tracker

A console-based Java application that manages student names and marks.

**Features**
- Input student names and marks
- Store data using arrays
- Calculate average marks
- Find the highest and lowest marks
- Display a student grade report
- Validate marks between 0 and 100

**Technologies:** Java, Arrays, Scanner, Eclipse IDE

## Task 2: Stock Trading Platform

A console-based Java application that simulates stock trading operations.

**Features**
- Display available stocks and sample prices
- Buy and sell shares
- Track the user's portfolio
- Check the available balance
- View transaction history
- Prevent purchases exceeding the available balance and sales exceeding owned shares

**Technologies:** Java, Object-Oriented Programming (OOP), ArrayList, Scanner, Eclipse IDE

**Note:** The stock prices are simulated. This application does not use live market data.

## How to Run

1. Download the required `.java` file.
2. Open Eclipse IDE.
3. Create a Java project and add the file to the `src` folder.
4. Run the class as a Java Application.
5. Follow the instructions displayed in the Console.
